# Дүрэм — Компанийн дүрмийн төсөл бүтээгч

Монгол хэлтэй, HTML/CSS/JavaScript статик вэб сайт. GitHub repository руу хуулж Vercel дээр байрлуулахад бэлэн. API түлхүүр, серверийн өгөгдлийн сан, төлбөртэй AI үйлчилгээ болон гаднын JavaScript сан шаардахгүй.

## GitHub → Vercel (код бичихгүйгээр)

1. ZIP-ийг задлаарай. `package.json`, `vercel.json`, `public`, `scripts`, `tests`, `README.md` зэргийг **GitHub repository-ийн үндсэн хавтас** руу байрлуулна. ZIP файлыг өөрийг нь upload хийхгүй.
2. GitHub дээр шинэ repository үүсгээд **Add file → Upload files → Commit changes** сонгоно. Эсвэл доорх Git командуудыг ашиглана.
3. [Vercel](https://vercel.com/new) дээр **Add New → Project → Import Git Repository** сонгож repository-гоо холбоно.
4. **Root Directory** нь `package.json` байгаа хавтас байна. Framework Preset: **Other**. `vercel.json` нь **Build Command: `npm run build`**, **Output Directory: `dist`** гэж тохируулна. Environment Variables шаардлагагүй.
5. **Deploy** дарна. Дараа нь GitHub-д commit хийх бүрт Vercel шинэ хувилбар байршуулна.

`company-charter` хавтсыг бүхэлд нь repository дотор байрлуулсан бол Vercel-ийн Root Directory-г `company-charter` гэж сонгоорой.

## Git командаар байрлуулах

Энэ төслийн хавтас дотроос ажиллуулна. Доорх `YOUR_ACCOUNT` болон `YOUR_REPOSITORY`-г өөрийн утгаар солино.

```bash
git init
git add .
git commit -m "Add Mongolian company charter generator"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```

## Компьютер дээр ажиллуулах

Node.js 20 буюу түүнээс шинэ хувилбар шаардлагатай. Dependency байхгүй тул `npm install` хийх шаардлагагүй.

```bash
npm run dev
```

Хөтчөөр `http://127.0.0.1:3000` хаягт нэвтэрнэ. `index.html`-ийг шууд double-click хийхгүй; ES module нь HTTP сервер шаарддаг.

```bash
npm test
npm run build
```

## Боломжууд

- 4 хэсэгтэй Монгол маягт, шууд шинэчлэгдэх дүрмийн урьдчилсан харагдац.
- ХХК, нээлттэй болон хаалттай ХК-ийн ерөнхий төслийн бүтэц.
- Энгийн болон нэг ангиллын давуу эрхийн хувьцаа, зарласан/гаргасан тоо, нэрлэсэн үнэ, хөрөнгийн тооцоо.
- ХК-ийн ТУЗ-ийн үндсэн тоон шаардлагын шалгалт.
- Хурлын болон ТУЗ-ийн нэмэлт бүрэн эрх, үйл ажиллагааны чиглэл, Ахмадын сангийн хэмжээ ба журам.
- Заавал бөглөх талбар, тоон хязгаарлалт, хувьцааны харьцаа, огнооны шалгалт.
- UTF-8 TXT татах, A4 хэвлэх, хөтчийн **Save as PDF** ашиглан PDF хадгалах. DOCX үүсгэхгүй.
- Хэрэглэгч товч дарсан үед localStorage-д хадгалах, сэргээх, устгах.
- Гар утасны өргөнд тохирох CSS, keyboard focus, талбарын label, алдааны холбоос.

## Хуулийн хамрах хүрээ

Энэ нь **загварт суурилсан төсөл**. AI чат, хууль зүйн дүгнэлт, улсын бүртгэлийн үйлчилгээ биш. Хэрэглэгчийн оруулсан эрх зүйн нөхцөл хуульд нийцэж байгаа эсэхийг программ утгаар нь шалгахгүй. Бүрдэл зөв болсныг хуульд бүрэн нийцсэн гэж ойлгож болохгүй.

| Заалт | Код / маягт дахь агуулга |
| --- | --- |
| 16.2.1 | Бүрэн, товчилсон нэр; ХХК/ХК ялгах тэмдэглэгээ |
| 16.2.2 | Зарласан, гаргасан хувьцаа; төрөл; нэрлэсэн үнэ; хөрөнгө |
| 16.2.3 | Давуу эрхийн хувьцааны тоо болон эзэмшигчийн эрх |
| 16.2.4 | ТУЗ байгаа эсэх, гишүүдийн тоо |
| 16.2.5 | Хурлын болон ТУЗ-ийн хуулиас бусад бүрэн эрх |
| 16.2.6 | Үйл ажиллагааны чиглэл |
| 16.2.7 | Бусад зохицуулалтын засварлах талбар ба суурь нөхцөл |
| 16.2.8 | Ахмадын сан, мөнгөн хөрөнгийн хэмжээ, журам |
| 16.3, 16.4 | Хуульд нийцсэн нэмэлт нөхцөл; дүрэмтэй танилцах эрх |

16.2.7 бол бусад зүйлд заасан шаардлагыг хамруулдаг заалт. Энэ программ бүх салбар болон бүх компанийн хувьд уг шаардлагыг бүрэн автоматжуулаагүй. Төрийн/орон нутгийн өмч, банк, даатгал, ББСБ, хөрөнгө оруулалтын сан, гадаадын хөрөнгө оруулалт, олон ангиллын давуу эрхийн хувьцаа болон тусгай нөхцөлтэй компанийн дүрмийг мэргэжлийн хяналтгүйгээр эцэслэхгүй. ХК-ийн бүртгэл, үнэт цаас гаргах процесс хэрэгжүүлээгүй.

Хувьцааны тоо 10¹² хүртэл; нэрлэсэн үнэ хоёр хүртэл орны нарийвчлалтай. Нийт дүн JavaScript-ийн аюулгүй бүхэл тооны хязгаарт (мөнгөн дүнг 100-аар үржүүлснээр) багтана. Олон ангиллын хувьцааг нэмэх бол тооцооллын загварыг өргөтгөнө.

## Нууцлал ба хөгжүүлэлт

Маягтын мэдээлэл серверт илгээгдэхгүй. Analytics, tracking, гаднын font/CDN байхгүй. Vercel нь сайт руу хандах ердийн HTTP хүсэлтийн техникийн мэдээллийг өөрийн бодлогын дагуу боловсруулах боломжтой. Хадгалсан төсөл browser localStorage-д шифрлэгдээгүй хэлбэрээр байна; нийтийн төхөөрөмжид хадгалахгүй. “Цэвэрлэх” нь тухайн сайтын хадгалсан төслийг устгана.

Хэрэглэгчийн текстийг HTML болгон оруулахгүй; DOM `textContent` ашиглана. Төслийг backend-тэй болгох үед сервер талын validation, authentication, retention, access control-ыг тусад нь хэрэгжүүлнэ.

## Шалгалтын хязгаар

Логикийн 9 автомат тест, JavaScript syntax, статик build амжилттай шалгагдсан. Ажлын орчинд npm команд байгаагүй тул package.json дахь ижил командуудыг `node --test tests/charter.test.mjs`, `node scripts/build.mjs` хэлбэрээр ажиллуулсан. Preview хөтөч локал серверт холбогдоогүй, HTTP шалгалт нь орчны socket эрхээр хаагдсан тул бодит хөтөч дээрх харагдац, TXT таталт, хэвлэх цонх, гар утасны эцсийн QA хийгдээгүй. Deploy хийсний дараа нэг туршилтын мэдээллээр 4 хэсгийг бөглөж, хадгалах/сэргээх, TXT, PDF, mobile харагдацыг шалгана.
